    How the scoring works
    • Entropy estimates guesswork: length × log2 of the character pool you actually use.
    • Length matters more than drama: correct-horse-battery-staple beats P@ss1 by a cosmic margin.
    • Detective work flags common passwords, keyboard runs (qwerty), sequences (1234), repeats (aaa) and leaked classics — each one collapses the score.
    • Crack times assume three attackers: a throttled website (100 guesses/s), a beefy offline rig (10 billion/s) and a nightmarish farm (1 trillion/s).
    • Reminder: strength is not safety. Unique passwords + a password manager + two-factor login beat any single clever password.
